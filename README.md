# EduTrack

EduTrack is a reusable command-line student performance analysis system built with **Python, NumPy, and Pandas**.

The goal is simple: clone the repository, provide a compatible student CSV, and EduTrack will validate, normalize, clean, analyze, and report the data — **without requiring any changes to the source code**.

---

## Features

1. CSV loading with automatic UTF-8 / Latin-1 fallback
2. Column-name whitespace normalization
3. Dataset schema validation
4. Automatic data cleaning and standardization
5. Dataset overview and health checks (missing-value counts per column)
6. Student search (by name)
7. Individual student report (by Student_ID)
8. Top-student ranking (by average score)
9. Class statistics (mean, median, std, min, max, grade distribution)
10. Attendance analysis
11. Study-time analysis (incl. correlation with average score)
12. Grade analysis (per subject)
13. Full report (all analyses combined)
14. Cleaned CSV export
15. Text summary export

## Setup

### 1. Clone

```bash
git clone https://github.com/utkarshcs18/EduTrack.git
cd EduTrack
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run with the default filename

Put a compatible CSV in the project directory named:

```text
studentData.csv
```

Then run:

```bash
python main.py
```

This launches the interactive menu (dataset overview, search, reports, analyses, exports, etc.).

### 4. Or run against another filename

```bash
python main.py --file my_students.csv
```

### 5. Non-interactive / scripted mode

To skip the menu and immediately clean the data, print the full report, and export both output files in one shot:

```bash
python main.py --file my_students.csv --report
```

No source-code changes are required for any of the above — EduTrack adapts to whichever compatible CSV you point it at.

## `studentData.csv` — required schema

`studentData.csv` (or whatever file you pass via `--file`) is the **input dataset** for EduTrack. It must be a CSV file containing the following 16 columns (leading/trailing spaces in header names are stripped automatically, so `" Name "` is treated the same as `"Name"`):

| # | Column | Description | Expected raw values |
|---|--------|-------------|----------------------|
| 1 | `Student_ID` | Unique identifier for the student | e.g. `STU0402` |
| 2 | `Name` | Student's full name | any casing, e.g. `shreya nair`, `KARAN DESAI` |
| 3 | `Gender` | Student's gender | `Male`, `Female`, `M`, `F`, etc. |
| 4 | `Age` | Student's age in years | positive integers, e.g. `16` |
| 5 | `Grade_Class` | Class/grade level | Roman numeral (`IX`, `XII`), numeric (`9`, `12`), or ordinal (`9th`, `12th`) |
| 6 | `Parental_Education` | Highest parental education level | e.g. `graduate`, `post graduate`, `ILLITERATE` |
| 7 | `Internet_Access` | Whether the student has internet access at home | `yes`/`no`, `y`/`n`, `1`/`0`, `true`/`false` |
| 8 | `Extracurricular_Activity` | Whether the student takes part in extracurriculars | `yes`/`no`, `y`/`n`, `1`/`0`, `true`/`false` |
| 9 | `Attendance_Percentage` | Attendance percentage | numeric, optionally with `%`, e.g. `86.6` or `86.6%` |
| 10 | `Study_Hours_Per_Week` | Hours spent studying per week | numeric float, `0`–`168` |
| 11 | `Math_Score` | Math exam score | numeric float, `0`–`100` |
| 12 | `Science_Score` | Science exam score | numeric float, `0`–`100` |
| 13 | `English_Score` | English exam score | numeric float, `0`–`100` |
| 14 | `Final_Grade_Letter` | Final letter grade | one of `O`, `A`, `B`, `C`, `D`, `F` |
| 15 | `Enrollment_Date` | Date the student enrolled | any common date format, e.g. `2021/06/06`, `09-12-2022` |
| 16 | `Remarks` | Free-text remarks (regenerated by EduTrack — see below) | any text (overwritten during cleaning) |

Renaming an arbitrary CSV to `studentData.csv` does **not** make it compatible — EduTrack first checks that all 16 required columns exist. If any are missing, EduTrack stops and reports exactly which columns are missing.

## EduTrack cleaning rules

### Name
Normalized to human-readable **Title Case**:
```text
shreya nair  -> Shreya Nair
KARAN DESAI  -> Karan Desai
```
(Person names are converted to Title Case, not `camelCase`.)

### Age
- Numeric only, must be a positive integer
- Invalid, negative, or non-integer values become missing (`NaN`)
```text
16      -> 16
"17"    -> 17
-5      -> missing
16.5    -> missing
```

### Grade_Class
Roman numerals and numeric forms are normalized into class ordinals:
```text
IX      -> 9th
9       -> 9th
9th     -> 9th
XII     -> 12th
12      -> 12th
```

### Parental_Education
Normalized to human-readable Title Case:
```text
graduate       -> Graduate
post graduate  -> Post Graduate
ILLITERATE     -> Illiterate
```
**Missing values are filled with `N/A`** (a literal placeholder, not blank).

### Internet_Access / Extracurricular_Activity
Normalized strictly to `Yes` / `No`. Accepted source equivalents: `yes`, `y`, `1`, `true`, `no`, `n`, `0`, `false`.
**Missing values are filled with `N/A`** (a literal placeholder, not blank).

### Attendance_Percentage
- Numeric/float, must be between `0` and `100`
- `%` signs are stripped when present
- Negative or greater-than-100 values are treated as invalid
```text
86.6% -> 86.6
86.6  -> 86.6
-5    -> invalid
```
**Missing or invalid values are filled with `0`.**

### Study_Hours_Per_Week
- Numeric float, must be non-negative
- Maximum possible value is `168` hours/week
- Invalid values are treated as invalid
**Missing or invalid values are filled with `0`.**

### Math_Score / Science_Score / English_Score
- Numeric floats, must be between `0` and `100`
- Invalid/out-of-range values (e.g. `"absent"`) are treated as invalid
**Missing or invalid values are filled with the literal text `Absent`.** These are excluded (treated as NaN) when EduTrack computes descriptive averages for reports, so a student's "Absent" subject doesn't drag down class-average stats — but see the note on `Final_Grade_Letter` below for how absent scores are used when calculating a missing grade.

### Final_Grade_Letter
Normalized to one of `O`, `A`, `B`, `C`, `D`, `F`.
- Passing grades: `O, A, B, C, D`
- Failing grade: `F`
- EduTrack automatically derives an additional column, `Final_Grade_Status`, set to `Pass` or `Fail` accordingly.
- If a source row contains `Pass` (or similar) without an underlying letter grade, EduTrack does **not** invent a letter directly from that text.

**If `Final_Grade_Letter` is still missing after normalization, EduTrack now calculates it** from the average of `Math_Score`, `Science_Score`, and `English_Score` — with any `Absent` subject counted as `0` in that specific average — using the standard scale:

| Average score | Grade |
|---|---|
| ≥ 90 | O |
| ≥ 80 | A |
| ≥ 70 | B |
| ≥ 60 | C |
| ≥ 50 | D |
| < 50 | F |

Because a grade is now always determinable this way, `Final_Grade_Letter`, `Final_Grade_Status`, and `Remarks` are **never left missing** in the cleaned output.

### Enrollment_Date
Mixed date formats are parsed when possible and exported consistently as `DD-MM-YYYY`:
```text
2021/06/06 -> 06-06-2021
09-12-2022 -> 09-12-2022
```
Unparseable/missing dates are left blank (no placeholder is invented for dates).

### Remarks
Regenerated from the (original or calculated) final grade, so remarks always stay consistent with the grade:

| Grade | Remark |
|---|---|
| O | Outstanding |
| A | Excellent |
| B | Good |
| C | Average |
| D | Need Improvement |
| F | Failed |

Any existing/inconsistent remarks in the source file are replaced by the standardized, grade-based remark.

### Missing / empty values — summary

| Column | If missing/invalid, becomes |
|---|---|
| `Parental_Education` | `N/A` |
| `Internet_Access` | `N/A` |
| `Extracurricular_Activity` | `N/A` |
| `Attendance_Percentage` | `0` |
| `Study_Hours_Per_Week` | `0` |
| `Math_Score` / `Science_Score` / `English_Score` | `Absent` |
| `Final_Grade_Letter` | Calculated from average score (Absent = 0) |
| `Final_Grade_Status` / `Remarks` | Always derived from the final `Final_Grade_Letter` |
| `Student_ID`, `Name`, `Gender`, `Age`, `Grade_Class`, `Enrollment_Date` | Left blank — never fabricated, since there is no reliable way to infer these |

Blank cells, whitespace-only cells, and common null tokens (`NaN`, `null`, `N/A`, etc.) in the source file are all recognized as missing before the rules above are applied.

## Data safety

EduTrack **never overwrites the original input CSV**. All generated files are placed in:

```text
output/
├── cleaned_student_data.csv
└── summary.txt
```

The cleaned CSV contains the normalized values plus the derived `Final_Grade_Status` column.
